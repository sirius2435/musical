# Image attributions

The Stage of Stories uses historical production photographs, playbills, theatre photography and creator portraits from Wikimedia Commons, plus one hero photograph supplied locally by the project owner. Every file is stored locally; no image is hot-linked from a third-party host.

All 35 images were accessed on **2026-11-01**. The Wikimedia set comprises 24 public-domain files, 2 CC0 files, 2 CC BY 4.0 files, 1 CC BY 2.0 file, 4 CC BY-SA 4.0 files and 1 CC BY-SA 2.0 file; the remaining hero PNG is supplied by the project owner. The 34 Wikimedia derivatives are WebP files resized, cropped or padded for the archive's layouts; the hero PNG is an unaltered copy. Public-domain images are credited for provenance even where attribution is not legally required. CC BY and CC BY-SA images are used under the licenses shown; where an image is adapted, the local derivative is shared under the same license.

A light CSS grade (saturation, warmth and contrast) is applied to production cards; the hero receives only interface-level cropping, brightness/contrast and atmospheric/spotlight overlays. The stored source files are not colour-edited. Historical images are presented as archival documents, not as official posters, endorsements or reconstructions.

## Editorial notes and unresolved media

- **Carousel (1945).** The only clearly licensed original-production photograph found on Wikimedia Commons is 815 × 520 px. It is used at card and detail size and is soft when enlarged; no higher-resolution, clearly licensed replacement was found.
- **Grease (1972).** No clearly licensed photograph of the original 1972 Broadway production was found. The production card and detail page use a CC BY-SA 4.0 photograph of The Muny's 2014 production, captioned as such rather than presented as the original.
- **The King and I (1951).** The portrait is from a 1951 souvenir program and is public domain because it was published without a copyright notice.
- **Minstrelsy.** The early-entertainment chapter uses a 1926 newspaper advertisement for a “real” minstrel show with Black performers as a critical historical document. It is not staged as decoration, and the chapter text explicitly frames blackface minstrelsy as racist performance history. No blackface caricature is used as a decorative hero or poster.
- **Creator portraits.** Clearly licensed portraits were found for Rodgers, Hammerstein, Bernstein, Sondheim, Loewe, Lerner, Laurents, Robbins and MacDermot. No clearly licensed portrait was found for Joshua Logan, Gerome Ragni, James Rado, Jim Jacobs or Warren Casey; those entries remain text-only rather than using a generic placeholder.
- **Source photography.** The hero is a stage photograph supplied directly by the project owner, used with permission and copied without alteration; it is not a Wikimedia image. The authentication page shows the Belasco Theatre auditorium. The introduction uses the Elgin Theatre, Toronto. The latter two are historic theatres, not production stills.
- **Downloads.** The 34 Wikimedia derivatives open as valid WebP images; the hero opens as a valid 1672 × 670 PNG and matches the supplied source file by SHA-256 (`7235079f4da1633ff197a2555cd68673e8c2fe853d4091aaa254401b48cb4da1`). All files are served from `frontend/public/images/`. No remote image URLs remain in page components.
