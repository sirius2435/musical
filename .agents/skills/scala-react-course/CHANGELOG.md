# Changelog

## V2 — 2026-11-01

沿用 V1 目录和渐进式加载。原始 `references/rules.txt` 字节不变，60 条和原始 SHA-256 保持一致。

- 新增 Scala 风格：val/var、命令式 for 与 for/yield、Try 与传统异常语法、结果类型、领域建模及 IO 边界。收紧项标为本次用户要求，不伪称核验了缺失课件。
- 修改 V1 中“不能据现有材料禁止传统异常语法”等旧结论：在本次明确要求下，Scala 新代码不用 try/catch/finally；Try 继续允许。samples 的差异保留在冲突记录。
- 补充 React 核心/展示/常量、Hooks 职责、无非响应式全局状态；新增私有 Zustand/get-use-set 示例，说明跨页面全局核心数据的定位和旧手册较宽表述的差异。
- 保留并校准后端消息、路由、表和资源示例，不改变既有 ID 契约；Resource 是有样例依据的推荐方案。
- 新增来源映射与冲突记录、11 个真实样例证据快照，明确 Lec2–Lec5 原始文件未取得及需人工核验项。
- SKILL.md 改为分析、设计、编码、自查、验证、交付六阶段，按语言和项目身份加载；Python/算法题/无关 TS 不套专项约束。
- 审查清单分九类，加入稳定检查项与 Critical/Major/Minor；推荐与未验证不自动判成强制违规。
- 新增 9 个行为 Prompt，含真实样例参考与 Python/算法/无关 TS 反向测试。它们是评估任务，不表示已完成独立 Agent 执行。
- 扩展包校验、结构反例测试与示例验证；新增可选 AGENTS 示例和官方安装说明。未修改其他项目配置或安装全局 Skill。
- 提供安装 ZIP；实际通过项、限制与未执行测试见 [审查报告](tests/review-report.md)。
